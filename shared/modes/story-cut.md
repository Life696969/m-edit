# Story-cut mode

## Goal

Create a truthful, tighter structure before any final visual editing.

## Method

- Work from the approved timestamped transcript.
- Select the strongest truthful opening, necessary context, body, proof, and ending.
- Remove repetition, false starts, dead ends, and low-value setup only when flow remains natural.
- Rearrange segments only when meaning and chronology remain honest.
- Document every kept, removed, and moved range.
- Prefer a slightly longer coherent cut over a shorter misleading one.
- Build the rough preview with simple cuts and original audio/video only.

## Common failures

- using a later line as a hook without enough context
- creating a claim by joining unrelated fragments
- hiding rearrangements
- adding final captions or effects before structural approval
- forcing a duration target that breaks meaning

## Review

Compare rough cut against the full transcript, listen for discontinuities, and disclose every material context risk.
