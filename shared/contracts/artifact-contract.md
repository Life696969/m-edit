# Artifact contract

## Before transcript approval

Allowed: `.m-edit/` control files, canonical transcript data, `transcript.md`, and `editing_plan.md`.

Forbidden: source cuts, target Remotion compositions, downloaded assets, previews, finals, or speculative next-phase work.

## After transcript approval

Allowed: optional story-cut artifacts, `video_editing_guide.md`, organized assets and ledger, Remotion code for the current clip, representative stills, one versioned preview, its verification JSON/contact sheet/report, and its hash-locked render recipe.

## After preview approval

Allowed: one final-quality render of the approved current clip, compared against the approved preview and recorded with verification/report artifacts.

## After all individual finals

A merged output is allowed only after a separate explicit merge request.

## Naming and location

Generated artifacts must remain inside the selected project and should live under the configured output root. Never overwrite a source file. Version previews rather than replacing an approved file in place.
