# Quality bar

A publishable edit should be:

- accurate: wording and meaning match the approved transcript
- understandable: visuals clarify rather than decorate
- readable: captions survive mobile playback and real backgrounds
- coherent: typography, motion, framing, assets, and audio form one system
- paced: dead air and visual resets reflect meaning, not arbitrary timers
- accessible: contrast, safe zones, motion intensity, and audio are considered
- faithful: final matches the approved preview
- auditable: sources, commands, hashes, approvals, and verification are recorded

## Red flags

STOP and revise when the agent rationalizes:

| Excuse | Reality |
|---|---|
| “The clip is simple, so transcript approval is unnecessary.” | Simple clips still produce wrong captions and trims. |
| “I only changed a tiny animation after approval.” | Any code or asset drift changes the approved artifact. |
| “The filename is unchanged, so approval still applies.” | Approval is hash-bound, not name-bound. |
| “I can prepare the next clip while waiting.” | That bypasses current-clip isolation and wastes work if feedback changes the system. |
| “The final looks close enough.” | Verify duration and visual fidelity against the approved preview. |
| “The asset is probably safe to use.” | Unclear rights require a safer substitute. |
