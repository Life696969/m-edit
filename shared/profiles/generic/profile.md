# Generic m-edit profile

This profile contains only cross-project defaults.

## Priorities

1. preserve source media, spoken meaning, and approved wording
2. make the content easier to understand or feel
3. keep important faces, actions, interfaces, products, and evidence visible
4. create one coherent visual/audio system with purposeful variation
5. verify preview/final fidelity and record decisions

## Defaults

- Preserve the original language and script unless translation is explicitly requested.
- Infer platform, aspect ratio, pacing, and tone only from the brief and footage.
- Use content-mode guidance instead of a universal editing template.
- Prefer accessible captions, local deterministic assets, and restrained motion.
- Preserve skin tone, audio clarity, and source detail.
- Put all generated artifacts under the configured output root.
- Network access, model downloads, package installation, and external assets require authorization.

## No assumptions

Do not assume any creator identity, audience, language, font, color palette, caption position, recurring visual effect, platform, resolution, or call to action.
