# Quickstart

1. Install FFmpeg, Python 3.10+, Node.js, and npm.
2. Install m-edit for your coding agent.
3. Open the agent in a trusted folder containing source video files.
4. Ask it to use m-edit to edit the videos and add captions.
5. Review `transcript.md`; correct uncertain wording and explicitly approve it.
6. Review the optional story cut when created.
7. Review each preview. Approval applies only to that version.
8. Receive one verified final per clip.
9. Ask for a merge only when a combined video is required.

Run `bin/m-edit doctor --project .` when setup or provider availability is uncertain.
